## 2. Overlap of existing work with each proposed component

| Proposed component | Overlapping prior work | Degree |
|---|---|---|
| Per-image vocabulary pruning before an OV detector | VocAda (#2) | **Full overlap.** Not claimable |
| Global CLIP image–text relevance for selection | VocAda-CLIP (text–text after captioning), standard CLIP zero-shot multi-label tagging, TagCLIP's global branch | High. Use as a baseline |
| Local (crop/patch) evidence aggregated with global | TagCLIP (#9) local-to-global; CastDet's region-level RemoteCLIP scoring (#5, training) | Medium-high. The new angle is aerial-specific multi-scale crops feeding a **detector's vocabulary** and evaluated by detection outcome |
| Uncertainty-aware retention | Conformal multi-label set prediction (general ML; specific papers to be cited in M6), VocAda's recall/precision trade-off discussion | Medium. The application to OVD vocabulary for aerial imagery appears untested |
| Adaptive vocabulary budget | Adaptive top-k / threshold selection is standard; LAE-DINO DVC varies the vocabulary during training | High as a standalone. Frame as part of the selector |
| Oracle headroom analysis on aerial imagery | Tsourveloudis (#3) | **Done** (with P/R/F1 and IoA). We re-measure with COCO mAP and as an upper bound |
